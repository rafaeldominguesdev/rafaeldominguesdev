# Rafael Domingues

Construo ferramentas de desktop para trabalhar com múltiplos agentes de IA no dia a dia.

## Projetos

### 🧭 [PilotDeck](https://github.com/rafaeldominguesdev/pilotdeck)
Quadro de tarefas self-hosted onde agentes de IA executam e você valida. MCP nativo, sem telemetria, seus dados na sua máquina.

### 💬 [Papinho](https://github.com/rafaeldominguesdev/papinho)
Chat de desktop com todos os seus agentes de IA (Claude, Codex, Grok...) juntos, num app só.

[![Baixar para macOS](https://img.shields.io/badge/Baixar-macOS-black?style=flat-square&logo=apple)](https://github.com/rafaeldominguesdev/papinho/releases/latest/download/Papinho.dmg)

### 📊 [AI Quota](https://github.com/rafaeldominguesdev/AI-Quota)
App de barra de menu para macOS que mostra quanto da sua cota de Claude Code, Codex, Cursor, Antigravity e Grok já foi usada.

[![Baixar para macOS](https://img.shields.io/badge/Baixar-macOS-black?style=flat-square&logo=apple)](https://github.com/rafaeldominguesdev/AI-Quota/releases/latest/download/AI-Quota.dmg)
